# Masmorra de Bolso 🗡️

Jogo 2D em pixel art desenvolvido em HTML5 Canvas e JavaScript.

## 🎮 Controles

- **← / → (Setas)**: Movimentar o personagem
- **Espaço**: Atacar

## 📁 Estrutura do Projeto

- `html/`: Contém a página principal do jogo (`index.html`) e sprites utilizados.
- `assests/`: Arquivos fonte de arte e sprites (`.png`, `.piskel`).

## 🚀 Como Executar

Abra o arquivo `html/index.html` em qualquer navegador web moderno.
